# 🗾 日本旅遊記帳（單檔版）

跟爸爸去日本旅遊用的記帳 App。手機瀏覽器直接開就能用，可手動輸入、拍收據 / Suica 截圖辨識，
自動換算台幣、分帳結算、圖表、匯出 CSV。

**配色可以隨心情換**：內建 6 種主題（夏日海洋 / 珊瑚礁 / 和紙彩 / 森林 / 檸檬蘇打 / 薰衣草天空），
外加深色模式與「自訂主色」混搭。在 App 頂端點 🎨 快速輪換，或到「設定 → 配色主題」挑。
換配色不會影響任何記帳資料。

- **只有一個檔案**：`index.html`，沒有安裝、沒有建置步驟。
- **資料存在你手機瀏覽器**（localStorage），不會上傳任何地方。
- **拍照辨識**用你自己申請的免費 Google Gemini 金鑰，金鑰只存在你手機。
- **配色主題**內建 6 種，隨時可換（頂端 🎨 或設定頁），不影響資料。

## 二、放到網路上（GitHub Pages，免費、不用信用卡）

做完這步你會得到一個網址，例如 `https://你的帳號.github.io/japan-expense/`，手機開這個網址就能用。

### 1. 註冊 / 登入 GitHub
- 到 <https://github.com/> → 右上角 **Sign up**（已有帳號就 Sign in）。

### 2. 建一個 repository
1. 登入後點右上角 **＋** → **New repository**。
2. **Repository name** 填：`japan-expense`
3. 選 **Public**（公開。程式碼裡沒有任何密碼，公開沒關係；你的記帳資料在手機本機，別人看不到）。
4. 勾 **Add a README file**。
5. 按 **Create repository**。

### 3. 上傳 index.html
1. 進到剛建立的 repo 頁面 → 點 **Add file** → **Upload files**。
2. 把這個資料夾裡的 `index.html` 拖進去。
3. 下方 **Commit changes**。

### 4. 開啟 Pages
1. repo 頁面上方 **Settings** → 左側選單 **Pages**。
2. **Source** 選 **Deploy from a branch**。
3. **Branch** 選 `main`、資料夾選 `/ (root)` → **Save**。
4. 等 1～2 分鐘，重新整理，上面會出現網址：
   `https://你的帳號.github.io/japan-expense/`
5. 點開，看到記帳畫面就成功了。

> 之後要改版：回到 repo → 點 `index.html` → 右上鉛筆圖示編輯，或用 **Upload files** 覆蓋 → Commit。
> 等 1 分鐘、手機重新整理就更新了。（或直接把新的 `index.html` 給我，我改好再給你覆蓋。）

## 三、申請 Google Gemini API 金鑰（拍照辨識用，免費）

### 1. 開 Google AI Studio
- 到 <https://aistudio.google.com/apikey> → 用你的 Google 帳號登入。
- 第一次會要你同意條款，按同意。

### 2. 建立金鑰
1. 點 **Create API key**（建立 API 金鑰）。
2. 如果問你要哪個專案，選 **Create API key in new project**（在新專案建立）。
3. 會產生一串像 `AIzaSyxxxxxxxxxxxxxxxxxxxxxxxxx` 的字 → 點旁邊複製。

### 3.（建議）限制金鑰用途，比較安全
1. 金鑰列表點該金鑰 → 進到 Google Cloud 的金鑰設定頁。
2. **API restrictions（API 限制）** → 選 **Restrict key** → 只勾 **Generative Language API** → 儲存。

### 4. 貼進 App
1. 打開你的記帳 App → 下方 **設定** → **📷 拍照辨識**。
2. 把金鑰貼到「API 金鑰」欄，點旁邊空白處讓它存起來。
3. 按 **測試金鑰是否可用**，看到「✅ 金鑰可以用！」就 OK。

> **免費額度**：Gemini 免費方案每天有相當多次的辨識額度，一趟旅行的收據量完全夠用。
> 若某次辨識失敗顯示額度訊息，過幾分鐘再試，或到設定把模型換成 `gemini-3.6-flash`。
> Google 偶爾會汰換模型名稱；若辨識一直失敗說模型不存在，跟我說一聲換新的名稱即可。

## 四、裝到手機主畫面（像 App 一樣）

## 五、開始用

- **記一筆**：下方橘色 **＋**。只有「金額」和「分類」是必填，其它想填再填。
- **拍照辨識**：在「記一筆」畫面上方按 **📷 拍收據 / 選 Suica 截圖**。
  - 收據 → 自動填好金額、店名、分類，**你確認後再按儲存**。
  - Suica 交易截圖 → 列出多筆，勾選要加入的，可改金額，一次加入。
- **分帳**：每筆選「付款人（爸爸/我）」和「分攤（兩人平分/個人不分攤）」。
  首頁會顯示「旅程結束你要還爸爸多少」或「爸爸要還你多少」。
- **匯率**：設定 → 匯率，填 1 日圓 = 幾台幣。每筆會記下當時匯率；
  回台灣後可改成實際匯率，按「用目前匯率重算全部」。
- **匯出**：設定 → 資料備份 → **匯出 CSV**（Excel 可開，回來用其他工具分析）。
  建議每天旅行結束匯出一次備份。

## 六、注意事項

- 資料只存在**這一支手機的這個瀏覽器**。換手機、清除瀏覽器資料、用無痕模式 → 資料會不見。
  **請養成每天匯出 CSV / JSON 備份的習慣**（App 會提醒）。
- 「匯出 JSON 備份」含所有設定和記錄，可用「從 JSON 備份還原」在新手機還原。
- 拍照辨識需要網路（傳給 Google 辨識）；手動記帳完全離線可用。
- 想加功能或改風格，直接告訴我要什麼，我改好新的 `index.html` 給你覆蓋即可。
